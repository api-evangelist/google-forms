# Google Forms API

> The Google Forms API is a RESTful interface that lets you create and modify Google Forms programmatically, read form responses, set up watches for Cloud Pub/Sub notifications on form changes and new responses, and integrate forms with external applications. Authentication is OAuth 2.0 (authorization code) against Google's accounts.google.com authorization server; the API base is https://forms.googleapis.com/v1.

## APIs

- [Google Forms API v1](https://developers.google.com/forms/api): Create/read/update forms, read responses, and manage watches. Base URL https://forms.googleapis.com/v1.

## Operations

- Forms: createForm, getForm, batchUpdateForm, setPublishSettings
- Responses: listFormResponses, getFormResponse
- Watches: createWatch, listWatches, deleteWatch, renewWatch

## Notes

- As of June 30, 2026, forms created via the API default to an UNPUBLISHED state and must be published explicitly with setPublishSettings before they accept responses.
